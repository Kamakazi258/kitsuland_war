Want FF and Est. stats? Your key must be registered with FF Scouter first:
  1. Go to ffscouter.com and submit your Torn API key there.
  2. Come back here and press Refresh.
Without it, everything else still works and those two columns show "-".
Want live war Score? Your key needs faction API access (KitsuLand members only):
  1. This only works if your KitsuLand faction position already has the Faction API Access permission.
  2. Create a Limited Access key at torn.com > Settings > API Keys.
  3. Enter that key here. If you already saved a key, press Forget key first.
Without it, everything else still works and the Score column shows "No access".
